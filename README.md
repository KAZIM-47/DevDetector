# DevDetector🔍

A GitHub profile search tool that lets you look up any GitHub user and instantly view their profile stats, bio, repos, followers, and social links — with a clean dark/light mode toggle.

---

## 🚀Features

- Search any GitHub username via the GitHub REST API
- Displays profile info: avatar, name, bio, join date
- Stats: public repos, followers, following
- Social links: website, Twitter/X, company, location
- Dark / Light mode toggle
- "No results" error handling for invalid usernames

---

## 🛠️Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [GitHub REST API](https://docs.github.com/en/rest/users/users)
- [Space Mono](https://fonts.google.com/specimen/Space+Mono) (Google Fonts)
